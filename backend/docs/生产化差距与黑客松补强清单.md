## 二、黑客松 Demo 建议优先补强（按优先级）

### P0 · 路演前必须处理

1. **视频链路的现场兜底**
   - 当前 `/health` 显示 `ffmpeg_available=false`，视频文章会失败。
   - 方案 A：现场机器安装 FFmpeg并预跑一条视频；方案 B：接入参考后端的 Doubao 直接视频理解，去除 FFmpeg 依赖；方案 C：路演准备录屏/固定样例并明确图文主路径。

2. **外部服务失败的可演示兜底**
   - Luna、Tavily、微信页面任意一项超时都会阻断链路。
   - 为路演样例做“最近成功结果缓存”，外部请求失败时显示“使用最近核验结果”，不要直接报红色技术错误。

3. **错误提示人性化**
   - 将 Pydantic 的原始数组错误转换成中文：字段过长、链接无效、公众号访问受限、服务繁忙。
   - 前端不要展示 `loc/body/max_length` 等开发字段。

4. **演示数据与真实数据明确区分**
   - `/health.mock_mode=true` 时页面顶部必须显示“离线演示模式”，避免把 mock 信源当真实核验。

### P1 · 有时间就补，明显提升评委体验

5. **拆分核验与沟通方案接口**
   - 当前 `/api/verify` 调用两次：第一次核验，第二次带关系重新核验并出方案，重复搜索、慢且多花 Token。
   - 建议新增 `/api/solution`：直接消费第一次 report + 关系上下文，只生成 communication。

6. **服务端流式进度（SSE）**
   - 当前“正在核验来源/交叉比对/评估风险”是前端计时模拟。
   - 接入 SSE 后真实推送阶段、来源数量、耗时，更可信，也便于中断和重试。

7. **多个主张的选择**
   - 文章经常含 5-10 个健康主张，目前 Agent 只选一条。
   - 可返回 `claims[]`，前端默认高风险项，同时允许用户点选“还想核验哪一条”。

8. **证据卡片可追溯**
   - 每条结论对应具体来源摘录、发布时间、机构级别；点击展开原文。
   - 对“可信/误导/暂不判断”展示判定原因，不只给总结。

9. **长辈沟通效果反馈**
   - 增加“长辈接受了吗 / 是否继续转发 / 哪版卡片更好”三项轻量反馈，形成产品闭环和路演指标。

## 三、距离实际生产仍缺的重点功能

### 1. 异步任务与可靠性

- 视频下载、模型调用、搜索应进入任务队列（Celery/RQ/云任务），接口返回 task_id。
- 分阶段超时、指数退避、熔断、幂等键、任务取消。
- 外部服务降级策略和多供应商切换；避免单点依赖 Luna/Tavily/微信页面。
- 公众号抓取属于非稳定上游，需要缓存、访问频率控制和“复制正文”正式兜底。

### 2. 安全与滥用防护

- 用户认证、设备身份、速率限制、日配额、验证码/防刷。
- 严格 CORS，不能生产环境 `allow_origins=["*"]`。
- 请求体大小限制：Base64 图片、超长文本、视频下载都需限额。
- SSRF 防护：链接解析使用域名白名单、DNS/IP 校验，禁止内网/回环/重定向到私网。
- 模型提示注入隔离、输出 JSON 校验、URL 可信域名服务端硬过滤（当前已完成域名过滤基础版）。
- API 密钥进入密钥管理服务，不使用普通 `.env` 部署。

### 3. 医疗与内容安全

- 明确产品是“健康信息核验与沟通辅助”，不是诊断或治疗建议。
- 对停药、急症、偏方替代治疗、自伤等高风险内容配置硬规则与紧急就医提示。
- 医疗结论需要证据等级：指南/系统综述/临床研究/媒体报道不能混为一类。
- 来源发布时间与过期检查；不同国家/地区指南适用性说明。
- 审核日志、申诉与纠错机制；无法判断必须稳定拒绝下结论。

### 4. 数据与隐私

- 用户可能输入家人病史、用药、聊天截图，属于高敏感个人信息。
- 隐私政策、明确同意、最小化收集、传输/存储加密、数据保留期限、账户删除与数据导出。
- 图片和视频处理完立即清理；日志禁止记录原始正文、Base64、密钥和完整健康信息。
- 当前 IndexedDB 只适合单设备 Demo；生产需决定“纯本地”还是“跨设备加密同步”。

### 5. 可观测性与质量评估

- request_id、结构化日志、调用耗时、Token/费用、来源数量、错误类型指标。
- Sentry/错误追踪、服务健康告警、供应商成功率看板。
- 建立谣言测试集：主张提取准确率、引用真实性、判定一致性、沟通接受度。
- 提示词版本化、灰度发布、A/B 测试与可回滚。

### 6. 产品与交付

- 用户账号与跨设备记录同步（若产品选择云端记录）。
- 卡片模板管理、字体嵌入、微信分享 SDK/小程序承接。
- 无障碍：大字号模式、屏幕阅读器、颜色对比度、减少动效选项。
- PWA 的 Lucide/html2canvas 当前走 CDN，生产应本地打包，确保离线和国内网络稳定。
- 自动化部署、HTTPS、域名、CI/CD、环境隔离、数据库备份与回滚。
